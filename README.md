# Digital Fortress

Practical security and governance kits for teams that build and run AI agents.

## Free tools
- [agent-guardrails-baseline](https://github.com/digitalfortressaudit/agent-guardrails-baseline): a 15-minute baseline with 25 checks.
- [ai-security-starter-checklist](https://github.com/digitalfortressaudit/ai-security-starter-checklist): LLM audit prompts and a repo scanner.
- [ai-system-agent-inventory-register](https://github.com/digitalfortressaudit/ai-system-agent-inventory-register): AI system and agent inventory.
- [mcp-tool-pin-check](https://github.com/digitalfortressaudit/mcp-tool-pin-check): MCP tool drift checker.
